# Valvole

Valvole controllate pneumaticamente per isolamento, attuazione e controllo di processo.

| Modulo | Descrizione |
|--------|-------------|
| [Valvola a Solenoide](solenoid/index.md) | Valvola on/off semplice; nessun feedback di posizione |
| [Valvola a Manicotto](pinch/index.md) | Comprime un tubo flessibile; pressostato conferma posizione |
| [Valvola a Farfalla — Solenoide Singolo (SS)](butterfly/single_solenoid/index.md) | Ritorno a molla; feedback posizione via ZSL/ZSH |
| [Valvola a Farfalla — Doppio Solenoide (DS)](butterfly/double_solenoid/index.md) | Bistabile; mantiene ultima posizione; feedback ZSL/ZSH |
