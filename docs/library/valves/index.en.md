# Valves

Pneumatically controlled valves for flow isolation, actuation, and process control.

| Module | Description |
|--------|-------------|
| [Solenoid Valve](solenoid/index.md) | Simple on/off valve; no position feedback |
| [Pinch Valve](pinch/index.md) | Squeezes flexible sleeve; pressure sensor confirms position |
| [Butterfly Valve — Single Solenoid (SS)](butterfly/single_solenoid/index.md) | Spring-return; position feedback via ZSL/ZSH |
| [Butterfly Valve — Double Solenoid (DS)](butterfly/double_solenoid/index.md) | Bistable; holds last position; position feedback via ZSL/ZSH |
