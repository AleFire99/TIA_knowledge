# Deviatori

Deviano il materiale convogliato tra due o più percorsi di scarico tramite un meccanismo attuato pneumaticamente.

| Modulo | Descrizione |
|--------|-------------|
| [Deviatore a Manicotto](pinch_type/index.md) | Doppia valvola a manicotto che devia il materiale tra due percorsi |
| [Deviatore a Spina (Plug-Type)](plug_type/index.md) | Spina con guarnizione gonfiabile; adatto per polveri abrasive |
